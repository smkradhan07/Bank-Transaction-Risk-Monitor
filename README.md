# Bank Transaction Risk Monitor

## Project Overview

The **Bank Transaction Risk Monitor** is a Tableau visualization project designed to present banking transaction data and support transaction risk monitoring through interactive dashboards.

The project demonstrates data visualization, analytical thinking, and Business Intelligence dashboard development using Tableau.
